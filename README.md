# Лабораторная работа: Мониторинг через SNMP

## Описание
Реализация системы мониторинга PostgreSQL с использованием протокола SNMP.

## Содержимое проекта
- check_postgres.sh - скрипт проверки процессов PostgreSQL
- check_postgres_status.sh - скрипт с цветным выводом статуса
- system_monitor.sh - скрипт расширенного мониторинга системы
- test.png - график созданный с помощью RRDtool
- snmpd.conf - конфигурация SNMP агента
- README.md - эта документация

## Как использовать
1. Настроить SNMP агент на сервере с PostgreSQL
2. Установить SNMP клиент на машине мониторинга
3. Запустить скрипты:
```bash
chmod +x *.sh
./check_postgres_status.sh
./system_monitor.sh
```
