=== ДОКАЗАТЕЛЬСТВО VIEW-BASED ACCESS ===

Настроены 4 community с разными правами:

1. public - доступ только к системной информации (.1.3.6.1.2.1.1)
2. mylab - доступ только к процессам PostgreSQL (.1.3.6.1.2.1.25.4.2.1.2)
3. admin - доступ только к extend командам (.1.3.6.1.4.1.8072.1.3.2)
4. full - полный доступ ко всем OID (.1)

Добавлены 3 новых extend OID для PostgreSQL:
- pg_databases: количество баз данных
- pg_xact_commit: сумма коммитов во всех БД
- pg_size: общий размер всех БД в MB

Конфигурация на сервере в /etc/snmp/snmpd.conf
